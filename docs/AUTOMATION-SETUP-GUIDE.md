## 🔗 שלב 2: חיבור n8n לGoogle Sheets (10 דקות)

### **2.1 ייבוא הWorkflow:**
1. ✅ לך ל-n8n שלך: https://webmasterpro.app.n8n.cloud
2. ✅ לחץ על **"+"** (New Workflow)
3. ✅ לחץ על **"Import from File"**
4. ✅ העלה את הקובץ: `n8n-workflow-multibrawn.json`

### **2.2 הגדרת Google Sheets Credentials:**

#### **אם עדיין אין לך:**
1. ✅ בתוך ה-node "Google Sheets - שמירת ליד"
2. ✅ לחץ על **"Create New Credentials"**
3. ✅ בחר **"OAuth2"**
4. ✅ לחץ **"Sign in with Google"**
5. ✅ תן הרשאות לn8n לגשת לSheets שלך

#### **אם כבר יש לך:**
1. ✅ בחר את הCredentials הקיימים
2. ✅ שמור

### **2.3 עדכון Sheet ID:**
1. ✅ בתוך ה-node "Google Sheets - שמירת ליד"
2. ✅ ב-"Document" → **בחר את "Multibrawn CRM"** מהרשימה
3. ✅ ב-"Sheet" → בחר **"Sheet1"** או הSheet שיצרת
4. ✅ שמור

### **2.4 בדיקת Webhook:**
1. ✅ לחץ על node ה-Webhook
2. ✅ וודא שה-URL הוא:
   ```
   https://webmasterpro.app.n8n.cloud/webhook/6286a24e-50bb-48f2-8925-4f09b3533108
   ```
3. ✅ אם לא - עדכן את הURL בקובץ `contact.html`

### **2.5 הפעלת הWorkflow:**
1. ✅ לחץ על **"Active"** למעלה מימין
2. ✅ הWorkflow עכשיו פעיל! 🎉

## 🐛 פתרון בעיות נפוצות

### **❌ הנתונים לא מגיעים ל-Google Sheets**

**בדיקות:**
1. ✅ הWorkflow ב-n8n פעיל? (יש כתוב "Active"?)
2. ✅ הCredentials של Google מחוברים?
3. ✅ Sheet ID נכון?
4. ✅ יש הרשאות כתיבה ל-Sheet?

**פתרון:**
- לך ל-n8n → Executions
- לחץ על ה-execution האחרון
- ראה איפה יש שגיאה
- תקן את השגיאה

### **❌ Webhook לא עובד**

**בדיקות:**
1. ✅ ה-URL של הWebhook זהה בכל מקום?
2. ✅ האתר עלה לאוויר עם הקוד החדש?
3. ✅ אין שגיאות ב-Console? (F12 → Console)

**פתרון:**
- פתח F12 בדפדפן
- לך ל-Network
- שלח את הצ'אטבוט
- בדוק אם יש request ל-webhook
- אם יש שגיאה 404/500 → בעיה בn8n
- אם יש שגיאה CORS → בעיה בהגדרות

### **❌ WhatsApp לא נפתח**

**בדיקות:**
1. ✅ המספר נכון?
2. ✅ יש WhatsApp מותקן?
3. ✅ הדפדפן חוסם פופאפים?

**פתרון:**
- אפשר פופאפים בדפדפן
- בדוק את המספר (בלי 0, עם +972)
- נסה במכשיר אחר

## 📊 שימוש ב-CRM

### **סטטוסים:**
עדכן את עמודת "סטטוס" לפי התקדמות:
- 🆕 **New Lead** - ליד חדש שנכנס
- 📞 **Contacted** - יצרתי קשר
- 💬 **In Discussion** - בשיחות
- 📋 **Proposal Sent** - שלחתי הצעה
- ✅ **Closed Won** - נסגר בהצלחה! 🎉
- ❌ **Closed Lost** - לא הגיע לעסקה

### **הערות:**
השתמש בעמודת "הערות" לתיעוד:
- תאריך שיחה
- מה דיברתם
- מה הבטחת
- תזכורות

### **דשבורד:**
יצור Sheet נוסף בשם "Dashboard" עם:
```
=COUNTIF(N:N,"New Lead")  → כמה לידים חדשים
=COUNTIF(N:N,"Closed Won") → כמה נסגרו
=COUNTIF(N:N,"Closed Won")/COUNTA(N:N)*100 → אחוז המרה
```
